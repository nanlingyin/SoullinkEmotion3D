 QUICK START

从情绪，连接到你的角色。

点击情绪脉冲，观察 VAD 追向目标、停留，再逐渐回到基线。三维视图同时呈现 V / A / D，拖动可旋转；V–A、V–D、A–D 投影可直接编辑两个坐标，同时保留第三轴。

  1. 公模库：四款角色可切换，保留当前情绪并检测模型的真实 AU 覆盖率。
  2. FACS / AU：单独锁定眉、眼、嘴的动作单元；释放后回到情绪驱动。
  3. 模型映射：查看真实 Morph 名称与覆盖率，导出 JSON 后可修改候选名称、增益并导入。
  4. 导入 VRM：支持 VRM 0.x / 1.0，本地读取，不上传模型。仅有标准表情的模型会进入预设降级模式。

VAD 是 Valence / Arousal / Dominance（愉悦、唤醒、支配），范围均为 −1 到 1。动画权重用于表情插值；不是情绪识别概率。本地手动控制无需摄像头、训练或 AI 服务；文本语义通过本机 JEV 服务分析。

window.soullinkFace.triggerEmotion('happy', 0.9)
window.soullinkFace.setVAD({ valence: 0.8 })
window.soullinkFace.setAU('au12LipCornerPuller', 0.7)
window.soullinkFace.setAU('au12LipCornerPuller', null)
