# SoulLink paper research branch

This branch is reserved for materials associated with **SoulLink: Capability-Aware Continuous Affective Animation for 2D and 3D Avatars**.

The anonymous perceptual-study data release is pending the repository owner's explicit authorization. No participant-response CSV has been published in this branch. This page is not yet a data-download endpoint.

The existing TypeScript application is separate from the paper's Python allocation reference. Creating this research branch does not integrate that reference controller into the production application.
