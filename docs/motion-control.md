# 情绪联动、精确动作与连续表情（v0.4）

v0.5 新增 [九宫格转头、八向注视与实际角度](direction-control.md)，眼球绑定与旧版名义视线角度的差异见该说明。

v0.5.1 修正高强度下的模型代理表现：主要眉眼嘴形变可达到完整范围，高增益时连续减弱互相抵消的次要代理；自动闭嘴代理不再占据强烈嘴部表情的预算。手动锁定的区域保留原始混合规则，外部 ARKit 通道不做该代理增强。VAD 与 AU 强度公式保持原值。

「明显展示」一键设置表情 4×、风格细节 100%、眉眼嘴 2×，适合查看演示效果；「自然」恢复原有表现参数。默认表情过渡为 0.28 秒，保留速度连续，并恢复接近旧版的短时响应。表现参数保存在当前浏览器中，刷新后保留；界面会回读实际引擎设置。改变表现参数时恢复动画播放，让幅度变化立即可见。头部动作幅度仍在动作面板独立控制。

`window.soullinkFace.getSettings()` 可查看实际设置；`getState().pinnedAUs` 可检查当前手动 AU 锁定。

在「FACS & 姿态」顶部打开「动作与连续表情」。默认启用情绪联动：较高唤醒度/支配度让动作更明显、更快，较低时更克制、更慢。这是可调的动画规则，不是经过心理测量验证的唯一映射。动作开始时读取最新 VAD 目标；播放中保持该段参数，避免情绪自然衰减使节奏突然改变。

## 精确控制

编辑幅度、头部每次时长、速度或次数，会切换为精确手动控制。也可以直接选择该模式。再切回情绪联动时，面板数值作为基准。

| 参数 | 含义与范围 |
| --- | --- |
| 幅度 | 0–100%，相对于当前绑定；从静止开始的动作峰值。叠加情绪姿态/闲置动作后，最终头部姿态仍限制在 [-1, 1] |
| 头部每次时长 | 0.25–8 秒；一次点头是低头并恢复，一次摇头是左右往返并恢复 |
| 速度 | 0.25–3 倍；实际每次时长 = 时长 / 速度，头部最短 0.15 秒、最长 12 秒 |
| 重复 | 1–6 次；各次之间连续衔接 |
| 表情过渡 | 0.08–1.5 秒，约为到达新 AU 目标 95% 的参考时间；眉、眼、嘴响应略有区别 |
| 视线过渡 | 0.08–1.5 秒；进入与恢复均缓动 |
| 临时视线保持 | 0.2–10 秒，从指令开始计时，包含视线转入时间 |

眨眼默认每次 0.23 秒；速度和次数有效，精确模式下幅度同样有效。自动眨眼始终使用一次完整眨眼，不受手动动作幅度影响。「收回动作」在约 0.25 秒内结束头部动作，并把临时视线平滑交回原来的手动目标。

当前绑定的头部幅度 100% 约为点头 14.3°、摇头 18.3°；视线 x/y 的 100% 为 45°/35°，具体视觉效果取决于模型。仅对本项目绑定有效，不是跨模型的解剖角度保证。

## 语义参数

```text
轻轻点头两次，幅度30%，每次0.8秒。
用力快速摇头。
缓缓看左边，幅度50%，保持3秒。
点头三次，总共3秒，幅度40%。
```

「轻轻/小幅」对应 30%，「正常幅度」65%，「大幅/用力」90%，「最大幅度」100%。「慢慢」为 0.6 倍，「正常速度」1 倍，「快速」1.5 倍。未指定的参数沿用面板与情绪设置。

数字先提取为候选，再由 JEV 判断是否是当前肯定的动作要求；被否定、引用、取消或无关的数字不会仅凭正则直接执行。幅度、秒数、次数、倍速都有限制；超出范围时限制到可用范围。模型仍可能误判，可在「查看分析结果」检查 `actions`。

明确数字优先于定性词和情绪。指定头部动作秒数时，不再乘情绪、面板速度或「慢慢/快速」这样的定性速度；同一指令明确指定的数字倍速仍生效。「轻轻」只调整幅度。总时长会除以该指令次数得到每次时长。视线秒数表示总保持时间，与视线转向速度分别控制。

## 接口

```js
const face = window.soullinkFace;
face.playAction('nod', { amplitude: 0.3, duration: 0.8, repetitions: 2 });
face.playAction('shake', { amplitude: 0.5, speed: 1.2 });
face.playAction('blink', { amplitude: 1, duration: 0.25, repetitions: 2 });
face.glance(1, 0, 3, { amplitude: 0.5, response: 0.3 });
face.setGaze(-0.4, 0.2); // 精确手动目标；平滑到达，不被情绪缩放
face.setAU('au12LipCornerPuller', 0.3); // 固定该 AU，平滑到达
face.setAU('au12LipCornerPuller', null); // 平滑交回情绪层
face.stopActions();
face.configure({ emotionMotion: true, faceSmoothing: 0.5, gazeResponse: 0.3 });
face.getState().motion; // 实际动作幅度、每次时长、次数、进度、视线目标
```

`playAction(name)` 兼容旧接口。`emotion: false` 可对单次动作关闭联动。显式 `amplitude` 精确决定该动作幅度；显式 `duration` 精确决定每次时长，除非同时传入 `speed`。时长单位是引擎秒，全局时间倍率和暂停仍影响整条动画时间线。

## 连续性与优先级

AU 和放松眼睑采用保留速度的临界阻尼响应，换表情/手动目标不会重置中间状态；头部动作采用起止速度和加速度为零的曲线，同类动作重触发会保留当前位移和速度。点头、摇头、眨眼可以同时进行，替换同类动作会从当前动作平滑衔接。手动 AU 锁定优先于情绪与自动眨眼。

临时视线结束后交回原手动目标，新手动视线会取消临时视线。显式「全部重置」仍立即归零。ARKit/MediaPipe 直接输入保持原通道值及左右差异，不在传输层额外平滑。

`npm test` 包含不同帧率一致性、指定峰值/次数/时长、打断时位移与速度连续、视线进入与回归、AU 换目标与数值锁定、语义数字优先级等回归检查。真实模型语义验收使用 `npm run test:motion:live`，会产生实际 API 调用。
