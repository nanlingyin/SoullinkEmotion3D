# 九宫格转头、八向注视与角度（v0.5）

「头部 / 视线」页签提供头部九宫格（八方向＋居中）和眼睛八向注视＋回正。「九宫格」表示组合方向；实际头部旋转使用偏航、俯仰、侧倾三个独立角度。

方向以角色自身为准：水平正数＝角色左，负数＝角色右；垂直正数＝上仰/上看，负数＝低头/下看；侧倾正数＝向角色左侧歪头。正面观看时，角色左右与你的左右相反。

| 控制 | 范围 | 数值含义 |
| --- | --- | --- |
| 头部水平/偏航 | ±60° | 角色相对正面的转头角度 |
| 头部垂直/俯仰 | ±40° | 角色相对正面的仰俯角度 |
| 头部侧倾 | ±45° | 头部向左右歪的角度 |
| 双眼水平 | ±30° | 相对头部的眼球转角 |
| 双眼垂直 | ±25° | 相对头部的眼球转角 |

界面精度为 0.1°，API 可传有限浮点数；超范围会限制在表内范围。斜向快捷键同时设置水平和垂直轴为给定度数，组合旋转的总角度并非单轴度数。头部使用 YXZ 欧拉顺序；眼球相对头部转动，和头部朝向可分别设置。

## 实际绑定

四款内置 VRM 均有头部、左眼和右眼骨骼，使用真实骨骼旋转。v0.5 将 VRM Bone LookAt 的范围映射设为角度恒等映射，避免过去输入 45° 又被模型元数据压缩到约 4–6°。同时校正 VRM 0.x 的面部朝向基底，统一头部俯仰/侧倾方向；不修改模型资产。

导入模型时检测绑定能力。缺少眼球骨骼的表情代理模型只能近似视线，界面会标注；没有可用绑定时禁用相关控制，不声称实现了眼球角度。大角度可能暴露模型造型本身的眼睑/眼球遮挡问题。

## 连续控制

数字输入和方向快捷键设置持续目标，保持上一版的临界阻尼平滑。精确头部控制抑制情绪/闲置姿态偏移，避免输入 20° 后实际落到别的角度；独立触发点头/摇头时仍可叠加短动作。再次精确设头部目标会平滑接管进行中的头部动作。

眼球精确目标不受情绪幅度缩放。点击「交回情绪」平滑释放该部位；「全部重置」立即归零。手动控制会取消未完成的语义结果。

## 接口与语义

```js
const face = window.soullinkFace;
face.setHeadAngles({ yaw: 25, pitch: 10, roll: -5 });
face.setGazeDegrees({ yaw: -12, pitch: 8 });
face.headDirection('up-left', 20);
face.gazeDirection('down-right', 15);
face.releaseHeadControl();
face.releaseGazeControl();
face.getState().angles; // 目标与平滑中的当前角度
face.getRigState(); // 模型能力和实际骨骼角度
await face.reactToText('头部向左转25度，眼睛向右看10度。');
await face.reactToText('只让眼睛看向右上方，每轴12度，头部保持不动。');
```

方向字符串：`up-left`, `up`, `up-right`, `left`, `center`, `right`, `down-left`, `down`, `down-right`。旧 `setPose`、`setGaze` 接口仍接受归一化参数；`frame.pose` 保留旧角度缩放单位，新的大角度可能超出 [-1, 1]，读取实际度数请用 `angles`。

语义分别判断头部、侧倾和眼睛方向，再对明确的角度候选做轴与部位归属判断。支持中文数字（如「抬头十五度」）、否定、引用和更正。头部定向保持到下一次控制；语义临时注视沿用保持时间，到期交回原来的目标。精确数字优先于情绪幅度；模型仍可能误判，可检查分析结果。

`npm test` 检查角度精度、连续接管、帧率一致性，并在四个实际 VRM 的头/眼骨骼上验证各方向、度数及世界空间转向。`npm run test:directions:live` 发起真实 JEV 请求验收角度归属与头眼分离。
